# Breaking Architectural Changes

The following architectural decisions were introduced.

- Export functionality moved into Shared Export Center.
- Procedure rendering moved into Shared Procedure Renderer.
- Documentation Intelligence became the only repository intelligence engine.
- Analysis pages no longer expose export functionality.
- Only final deliverables expose Generate Documentation and Export.

These changes affect all future platform development.

# Known Limitations

Current limitations include

- Coverage Intelligence V2 not implemented.
- Documentation Generation V2 not implemented.
- Documentation currently generates summaries rather than production-ready documentation.
- Explainable AI not implemented.
- Confidence engine not implemented.
- Configurable Workflow GIFs not implemented.
- Video Intelligence not implemented.

These are tracked in the Master Product Backlog.
