Feature Description

Support ticket SAV-3001 revealed customers cannot configure connectors because the documentation does not mention required service account prerequisites. This documentation will update the "Using Templates" section to include the necessary details for users to successfully configure connectors.

Capabilities

  • Identify required service accounts.
  • Specify necessary permissions.
  • Outline access prerequisites.
  • Define environmental requirements.
  • Provide a pre-configuration checklist.

User Roles

  • End users who configure connectors.
  • Administrators responsible for setting up service accounts.

Prerequisites

  • Required service account details are not provided.
  • Required permissions details are missing.
  • Access prerequisites are not specified.
  • Environmental requirements were not given.
  • Pre-configuration checklist is unavailable.

Procedure

  • The procedure for updating the documentation is not currently provided.

Expected Result

  • After following the updated documentation, users can configure connectors successfully..
